# [UI-020] — Nguyên liệu ở trang món chuyển sang dạng danh sách ảnh nhỏ

**Mã task:** UI-020 · **Giai đoạn:** GĐ4 · **Loại:** Frontend

## Yêu cầu của chủ dự án (2026-11-01)

Thẻ hiển thị nguyên liệu trong trang chi tiết ảnh đang to quá, chiếm diện tích
hiển thị lớn nhất là trên mobile — đổi sang dạng danh sách: ảnh nhỏ nằm bên trái,
bên phải là tên và thông tin, tiện cho người dùng xem và liệt kê nguyên liệu.

## Việc đã làm

- Mục "Nguyên liệu · một khẩu phần" ở trang chi tiết món: bỏ lưới thẻ
  `ld-dcard` (ảnh 4:3 lớn), thay bằng **danh sách `ld-group`** — mỗi dòng là một
  liên kết tới trang nguyên liệu: ảnh thu nhỏ 52×52 bo góc bên trái (class
  `.ld-thumb` trong app.css), bên phải là tên nguyên liệu (đậm) và dòng thông
  tin gồm định lượng + đơn vị, ghi chú, nhãn "Tuỳ chọn" / "Phần bỏ đi" khi có;
  mũi tên điều hướng ở cuối dòng.
- Ghi chú kiểm chứng dữ liệu: API chi tiết món chỉ trả `id/slug/name_vi/image`
  cho nguyên liệu (không có nutrition) nên chân thẻ cũ "kcal/100g" thực tế luôn
  trống — dạng danh sách không mất thông tin nào so với trước.
- Lưới thẻ lớn vẫn giữ ở các trang duyệt (Thư viện, trang chủ, lắc) — chỉ trang
  chi tiết món đổi sang danh sách theo đúng yêu cầu.

## Kiểm chứng

view:cache đạt; trang món thật chứa markup danh sách mới và không còn
`ld-grid-ing`; Pest toàn cục đạt (xem commit).

**Đính chính quy trình (2026-11-01, sau phản ánh của chủ dự án kèm ảnh chụp):**
lần triển khai đầu quên chạy `npm run build` sau khi sửa `resources/css/app.css`
— Blade đã dùng class `.ld-thumb` mới nhưng file CSS phục vụ thực tế (bundle
Vite có hash) chưa có class đó, khiến ảnh nguyên liệu hiển thị ở kích thước gốc
khổng lồ và tràn ngang trang. Đã build lại (bundle mới chứa `.ld-thumb`, trang
tham chiếu đúng bundle mới). **Bài học bắt buộc: sửa CSS/JS xong phải
`npm run build` và kiểm tra bundle đã build chứa thay đổi — view:cache không
thay thế được bước này.**

**Tinh chỉnh theo yêu cầu chủ dự án (2026-11-01):** ảnh thu nhỏ hạ xuống
**48×48px**, bo góc giảm còn **10px**; thêm class `.ld-row-compact` cho dòng
nguyên liệu — padding 9px/12px (thường 12.5px/16px), cỡ chữ 14.5px (thường
15.5px), dòng phụ 13px, khoảng cách 10px. Đã build lại và kiểm chứng bundle.

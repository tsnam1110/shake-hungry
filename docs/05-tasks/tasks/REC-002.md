# [REC-002] — Sinh embedding + tìm món tương tự bằng pgvector

**Mã task:** REC-002 · **Giai đoạn:** GĐ4 · **Loại:** Backend
**Status:** ⬜ TODO · **Ngày tạo:** 2026-08-31 · **Phụ thuộc:** REC-001

## Mục tiêu

Cải thiện thành phần `đa_dạng` của engine chấm điểm bằng độ tương tự ngữ nghĩa thật, thay cho
heuristic.

## Việc cần làm

1. Sinh embedding cho mỗi món từ: tên món + nguyên liệu chính + cách chế biến + vùng miền.
2. Lưu vào `dishes.embedding`, index `ivfflat`.
3. Thay `đa_dạng` bằng: `1 − cosine(embedding_món, trung_bình_embedding_5_bữa_gần_nhất)`.
4. Lệnh artisan sinh lại embedding hàng loạt khi món đổi.

## Definition of Done

- [ ] Mọi món published có embedding
- [ ] Truy vấn "món tương tự" trả kết quả hợp lý (kiểm tay 10 món)
- [ ] Engine vẫn chạy được nếu embedding thiếu (fallback heuristic)
- [ ] Truy vấn vector <100 ms với 500 món

## Cạm bẫy

- Món mới thêm phải sinh embedding, nếu không sẽ luôn bị coi là "khác biệt tối đa" và được ưu tiên
  gợi ý một cách sai lệch.
- Đổi mô hình embedding ⇒ phải sinh lại **toàn bộ**, không trộn hai mô hình.

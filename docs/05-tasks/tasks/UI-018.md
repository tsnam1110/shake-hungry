# [UI-018] — Hệ thống góp ý, phản hồi dạng ticket

**Mã task:** UI-018 · **Giai đoạn:** GĐ4 · **Loại:** Frontend + Backend
**Status:** ✅ DONE · **Ngày xong:** 2026-11-01 · **Ngày tạo:** 2026-11-01 · **Phụ thuộc:** UI-008, ADM-001

---

## Yêu cầu của chủ dự án (2026-11-01)

Thêm hệ thống góp ý, phản hồi: ở mỗi trang sản phẩm có nút để người dùng gửi phản hồi
lên hệ thống; phản hồi vào ở trạng thái ticket **đã ghi nhận và chờ duyệt**; chỉ người
dùng đã đăng nhập mới gửi được; loại phản hồi gồm: góp ý, hỗ trợ, phát triển, lỗi.

## Việc đã làm

- **Backend:** bảng `feedback_tickets` (migration `2026_11_01_100007`, DATA-MODEL đã
  cập nhật): người gửi, `type` (`gop-y`/`ho-tro`/`phat-trien`/`loi`), tiêu đề tuỳ chọn,
  nội dung, ngữ cảnh tuỳ chọn (món/quả/nguyên liệu + trang gửi), `status` mặc định
  **`da-ghi-nhan`** (nhãn hiển thị "Đã ghi nhận · Chờ duyệt"), ghi chú quản trị.
  API người dùng (bắt buộc đăng nhập): `POST /api/feedback`, `GET /api/feedback`
  (ticket của tôi). API quản trị: `GET /admin/api/feedback` (lọc trạng thái/loại),
  `POST /admin/api/feedback/{id}/status` (đổi trạng thái + ghi chú; các trạng thái:
  da-ghi-nhan, da-duyet, dang-xu-ly, da-xu-ly, da-dong).
- **Phía người dùng:** hộp thoại "Gửi phản hồi" dùng chung ở layout (chọn loại dạng
  chip, tiêu đề, nội dung; khách chưa đăng nhập thấy lời nhắc + nút đăng nhập thay
  cho biểu mẫu). Nút "Gửi phản hồi" đặt ở trang chi tiết **món, hoa quả và nguyên
  liệu**, tự gắn ngữ cảnh sản phẩm + trang. Trang hồ sơ thêm mục **"Phản hồi của
  tôi"**: danh sách ticket kèm nhãn loại và trạng thái.
- **Phía quản trị:** trang "Góp ý · Phản hồi" trong admin (antd): bảng ticket lọc
  theo trạng thái (mặc định mở ở hàng chờ duyệt) và loại, đổi trạng thái ngay trên
  bảng, xem chi tiết + ghi chú xử lý trong hộp thoại.
- **Test:** `FeedbackTest` — khách bị 401; gửi thành công và đúng trạng thái khởi
  tạo; gắn ngữ cảnh món; 422 khi sai loại/nội dung ngắn/không tồn tại; quản trị
  xem được hàng chờ và đổi trạng thái, người thường bị 403 ở API quản trị.

## Kết quả kiểm chứng (2026-11-01)

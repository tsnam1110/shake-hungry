## Mục tiêu

Tính `dish_tcm_summary` từ nhãn nguyên liệu, theo trọng số khối lượng cộng hệ số chế biến.

## Công thức

```
nature_score = Σ(khối_lượng_i × điểm_tính_i) / Σ(khối_lượng_i)     (chỉ nguyên liệu CÓ nhãn)
điểm_tính:  hàn = −2 · lương = −1 · bình = 0 · ôn = +1 · nhiệt = +2

nature_score += hệ_số_chế_biến
   chiên/nướng/kho +0,5 · xào +0,25 · luộc/hấp −0,25 · sống −0,5

coverage_pct = Σ(khối_lượng có nhãn) / Σ(tổng khối_lượng) × 100
```

Chi tiết: [NGU-HANH-AM-DUONG §4](../../08-cultural/NGU-HANH-AM-DUONG.md).

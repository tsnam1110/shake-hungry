## Mục tiêu

Dựng khu vực quản trị. **Đây là công cụ sản xuất dữ liệu chính của dự án**, không phải phần phụ —
xem [ARCHITECTURE §5.6](../../02-architecture/ARCHITECTURE.md).

## Kiến trúc

- **Frontend:** React 19 + **Ant Design (antd) 6** (ghim major 6 khi cài), build bằng Vite trong cùng repo,
  phục vụ tại `/admin`. Mọi màn hình dựng từ component antd (Table, Form, Modal,
  Select, Upload...) để đồng nhất và nhập liệu nhanh.
- **Backend:** Laravel — API nội bộ dành riêng cho trang quản trị + xác thực
  đăng nhập theo phiên (session) dùng chung hệ tài khoản `users`. Phân quyền
  kiểm ở backend; giao diện chỉ hiển thị theo quyền, không tự quyết.

## Việc cần làm

1. Dựng khung SPA antd tại `/admin`: layout (menu, header), trang đăng nhập,
   cơ chế gọi API kèm xử lý hết phiên.
2. Đăng nhập bằng email/mật khẩu. Không cần OAuth.
3. Hai vai trò: `admin` (toàn quyền) và `editor` (biên soạn dữ liệu, không sửa cấu hình).
4. Bật ghi log thay đổi để truy nguyên ai sửa gì.

## Definition of Done

- [ ] Đăng nhập được vào `/admin`, giao diện toàn bộ bằng component antd
- [ ] Hai vai trò hoạt động đúng (kiểm ở backend)
- [ ] Có tài khoản seed cho môi trường dev (mật khẩu **không** commit)
- [ ] Log thay đổi ghi được

## 5. Bất thường ghi nhận — chờ pha phân xử riêng (KHÔNG tự sửa trong đợt này)

Đã ghi chi tiết trong `import_note` từng file. Tổng hợp theo mức ưu tiên:

### Ưu tiên cao — đồng thuận 3/3 nguồn hoặc liên quan phân loại/mô hình calo

1. **ca-dieu-hong-sot-ca — phân loại phương pháp:** cả 3 nguồn đều *chiên cá giòn rồi rưới
   sốt*; file giữ `cooking_method=kho` (bản kho vẫn tồn tại ở nguồn phụ). Đổi method sẽ kéo
   theo mô hình hấp thụ dầu CALC-004 — cần quyết riêng.
2. **bun-bo-nam-bo — vùng miền:** Dân Việt + SKĐS đều khẳng định món gốc Hà Nội (phố Nam Bộ);
   file để `region=vn-south` và tên Anh "Southern..." — đề xuất xem lại ở pha phân xử.
3. **banh-tam-bi:** cả 3 nguồn đều có **bột nếp** trong sợi bánh — file thiếu hẳn; cả 3 nguồn
   ăn kèm giá/dưa leo/rau thơm — file thiếu; thính nguồn 150 g/mẻ vs 10 g optional của file.
4. **hu-tieu:** cả 3 nguồn đều có **thịt băm xào tỏi** (sốt thịt đặc trưng Nam Vang) — file
   thiếu; 2/3 nguồn có tim lợn, tôm khô, củ cải trắng — file thiếu.
5. **bun-cha:** file dùng **đu đủ chín** làm dưa góp — cả 3 nguồn dùng **đu đủ xanh** (+su
   hào), nhiều khả năng ánh xạ nguyên liệu sai; cả 3 nguồn ướp thịt bằng hành tím băm — file
   thiếu.
6. **com-ca-kho:** cả 3 nguồn đều kho bằng **nước dừa tươi + nước màu** — file thiếu cả hai.
7. **canh-rau-day:** thiếu **mướp** (3/3 nguồn; cũng là bất thường tiếp nối canh cua).
8. **muc-xao-dua:** thiếu **hành tây** (3/3 nguồn đều xào chung dứa + hành tây).
9. **canh-cai-thit-bam:** thiếu **hành tím** (3/3 nguồn phi thơm trước khi xào thịt).
10. **canh-trung-ca-chua:** thiếu **ngò rí** (3/3 nguồn); **canh-khoai-mo:** thiếu **ngò
    gai** (3/3 nguồn).
11. **cha-ca-la-vong:** thiếu dòng **mẻ** (3/3 nguồn ướp cá bằng mẻ; file thay bằng dấm gạo);
    nguồn gốc dùng cá lăng — file dùng cá lóc (biến thể phổ biến, chỉ ghi nhận); dòng rau răm
    0/3 nguồn có.
12. **vit-om-sau:** thiếu **sả + gừng** (3/3 nguồn); nguồn dùng khoai sọ, file dùng khoai môn.
13. **ca-ro-kho-to:** thiếu **thịt ba chỉ/mỡ heo** (3/3 nguồn kho kèm) + nước dừa/nước màu.
14. **mam-kho:** thiếu **tôm** (cả 2 công thức ĐMX + Cookpad) và **đậu bắp/nấm rơm** (3/3
    nguồn); nêm đường 2/3 nguồn.
15. **bun-rieu-cua:** ĐMX + Cookpad đều có tôm khô + mực khô + trứng gà trong chả riêu và hầm
    sườn/xương — file thiếu.
16. **bun-moc:** file dùng **gio-lua thay giò sống** quết mộc nhĩ — mọc đúng nghĩa là giò
    sống (bước nấu đã viết lại theo giò sống và nêu bản rút gọn); thiếu chả quế/chả lụa riêng,
    mắm tôm, hành phi.
17. **bun-oc:** file là biến thể chuối đậu (chuối + tiết + đậu) trong khi 2/3 nguồn là bản cổ
    truyền chỉ có ốc; nguồn tạo chua bằng giấm bỗng (~55 ml/khẩu phần), file thay bằng dấm
    gạo 5 g.
18. **canh-mong-toi-tom:** nguồn dùng **tôm khô** (2/3) trong khi file dùng tôm tươi; khoai
    sọ ở 2/3 nguồn, file không có.
19. **banh-da-cua:** thiếu sườn ninh + tôm + me tạo chua (2–3/3 nguồn).

### Ghi nhận khác (đồng thuận 2/3 hoặc khác biệt biến thể)

- **gia-cay:** thiếu mẻ (2/3); nguồn ướp riềng tươi, file dùng bột riềng.
